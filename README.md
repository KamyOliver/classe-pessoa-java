# classe-pessoa-java

Projeto em Java que demonstra o uso de classes, objetos e sobrecarga de construtores, com criação e exibição de dados da classe Pessoa.

**Funcionalidades**

Criação de objetos da classe Pessoa
Uso de diferentes construtores
Exibição dos dados das pessoas
Demonstração de sobrecarga de construtores

**Conceitos aplicados**

Classes e objetos
Construtores
Sobrecarga de construtores
Encapsulamento (atributos privados)

**Estrutura do projeto**

Pessoa.java → Classe principal com atributos e construtores
TestePessoa.java → Classe de teste com criação de objetos

**Como executar**

Compile e execute pelo terminal:
javac Pessoa.java TestePessoa.java
java TestePessoa

**Objetivo**

Projeto acadêmico desenvolvido para praticar conceitos básicos de Programação Orientada a Objetos em Java.
